# Track: Gestión Operativa de Reservas y Huéspedes

## ID: booking_ops_20260211
## Estado: En Planificación

## Descripción
Este track se enfoca en convertir el calendario visual (Tape Chart) en una herramienta operativa real. Permitirá visualizar, crear y gestionar el ciclo de vida de una reserva de forma integrada con el módulo de huéspedes.

## Objetivos
- Visualizar reservas reales en el calendario.
- Flujo de creación de reserva con búsqueda de huéspedes.
- Gestión de estados (Check-in/Check-out).
- Persistencia y validación de solapamientos en tiempo real.
