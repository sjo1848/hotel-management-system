# Track: Dashboard de Informes y Análisis

## ID: dashboard_analytics_20260211
## Estado: En Planificación

## Descripción
Este track se enfoca en transformar el Dashboard actual (que usa datos estáticos) en una herramienta de inteligencia de negocio con datos reales. Proporcionará métricas clave sobre ocupación, ingresos y actividad operativa.

## Objetivos
- Implementar endpoints de agregación en el backend para métricas.
- Mostrar % de ocupación real en el Dashboard.
- Visualizar ingresos acumulados y proyecciones.
- Listar alertas operativas (llegadas hoy, salidas hoy).
