## 3. Discovery

### Hallazgos
- usan planillas y mensajeria informal para coordinar recepcion y limpieza
- los cambios de habitacion no siempre quedan claros
- los cierres de caja dependen de una sola persona
- no tienen una vista central del turno ni planner de inventario

### Restricciones
- quieren evitar una implementacion en temporada alta
- pueden nombrar owner operativo
- pueden entregar habitaciones, usuarios y reglas base

### Conclusion
- fit: `alto`
- dolor principal: coordinacion operativa y control de caja
- plan sugerido: `Pro`
- siguiente paso correcto: demo orientada a flujo operativo

## 4. Demo recomendada

### Orden de demo
1. `Recepcion`

3. `Planner de habitaciones`

### Objetivo de la demo

- bajar objeciones
- preparar propuesta economica
