# HMS Elite — Onboarding de Cliente

Fecha de referencia: 2026-03-09
Objetivo: que el alta de un cliente no dependa de improvisacion

## Etapas

### 1. Discovery

Objetivo:
- entender operacion, volumen y alcance

Checklist:
- cantidad de habitaciones
- cantidad de usuarios por rol
- flujo actual de reservas, check-in y checkout
- necesidad de caja y reportes
- necesidad multi-hotel

Salida:
- alcance acordado
- plan elegido
- fecha estimada de implementacion

### 2. Setup

Objetivo:
- dejar el tenant listo

Checklist:
- hotel creado
- usuarios base creados
- habitaciones cargadas
- pricing base cargado
- roles definidos

Salida:
- entorno configurado

### 3. Carga inicial

Objetivo:
- dejar el sistema utilizable

Checklist:
- habitaciones
- usuarios
- huespedes base si aplica
- reservas futuras si aplica
- datos comerciales minimos

Salida:
- datos iniciales validados

### 4. Capacitacion

Objetivo:
- que recepcion y operacion sepan usarlo

Bloques:
- recepcion
- habitaciones
- housekeeping
- admin/reportes

Salida:
- usuarios entrenados

### 5. Go-live

Objetivo:
- pasar a operacion real sin friccion

Checklist:
- credenciales entregadas
- flujo de check-in/check-out probado
- caja probada
- soporte habilitado
- responsable del cliente definido

Salida:
- cliente operando

## Riesgos a cubrir

- cargar habitaciones sin proceso operativo claro
- capacitar solo al owner y no al equipo real
- salir a vivo sin soporte definido
- no dejar responsable unico del lado cliente
