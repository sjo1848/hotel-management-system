# HMS Elite — Checklist de Go-Live

Objetivo:
- pasar a operación real con el menor nivel posible de improvisación

## 1. Setup

- hotel creado y validado
- usuarios creados
- roles revisados
- habitaciones cargadas
- precios base cargados

## 2. Operación

- front desk validado
- check-in probado
- checkout probado
- caja probada
- housekeeping probado

## 3. Datos

- reservas futuras cargadas si aplica
- huéspedes base cargados si aplica
- datos comerciales mínimos revisados

## 4. Capacitación

- recepción capacitada
- housekeeping capacitado
- admin capacitado
- owner validado

## 5. Soporte

- canal de soporte definido
- responsable del cliente definido
- severidades explicadas
- escalamiento aclarado

## 6. Validación final

- demo final aprobada
- checklist firmado internamente
- fecha y hora de salida acordadas

## 7. Día de salida

- responsable técnico disponible
- responsable funcional disponible
- monitoreo operativo activo
- bitácora de incidentes abierta

## 8. Post go-live

- seguimiento inicial de 24/48 horas
- incidencias registradas
- backlog inicial consolidado
