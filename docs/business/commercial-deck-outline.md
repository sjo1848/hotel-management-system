# HMS Elite — Deck Comercial Base

Objetivo:
- vender HMS Elite con un relato claro, no solo con features
- servir como base para un deck real de ventas

## Slide 1 — Qué es HMS Elite

Mensaje:
- PMS SaaS para operación hotelera seria, con foco en control operativo, financiero y multi-hotel

Texto sugerido:
- HMS Elite ordena recepción, habitaciones, caja y operación diaria desde una sola plataforma.

## Slide 2 — Problema

Dolores:
- check-in y checkout desordenados
- habitaciones mal liberadas
- cobros incompletos
- baja visibilidad del turno
- herramientas legacy lentas o fragmentadas

Texto sugerido:
- El hotel pierde tiempo, margen y control cuando opera con procesos fragmentados o software que no acompaña el ritmo del turno.

## Slide 3 — Qué resolvemos

Resultados:
- recepción más ordenada
- caja más controlada
- housekeeping más visible
- inventario mejor gestionado
- operación más trazable

Texto sugerido:
- HMS Elite convierte la operación hotelera en un flujo controlado, trazable y más fácil de ejecutar.

## Slide 4 — Cómo se usa

Recorrido corto:
- llega el huésped
- recepción lo gestiona
- se hace check-in
- se agregan cargos
- se hace checkout
- housekeeping libera habitación

Texto sugerido:
- El sistema acompaña al equipo desde la llegada del huésped hasta la liberación de la habitación.

## Slide 5 — Diferenciación

Puntos:
- arquitectura moderna
- multi-hotel real
- control operativo fino
- performance y seguridad
- UX más clara para operación diaria

Texto sugerido:
- No es solo otro PMS: está pensado para operar rápido, con menos errores y con base técnica más sólida.

## Slide 6 — Para quién aplica

Segmentos:
- hotel independiente
- grupo chico
- cadena mediana
- operador que necesita control multi-propiedad

Texto sugerido:
- Aplica tanto para un hotel independiente como para una operación con varias propiedades que necesita control central.

## Slide 7 — Implementación

Mensajes:
- onboarding guiado
- setup inicial
- capacitación por rol
- go-live acompañado

Texto sugerido:
- La implementación se estructura en discovery, setup, carga inicial, capacitación y go-live.

## Slide 8 — Soporte

Mensajes:
- severidades claras
- escalamiento
- seguimiento post go-live

Texto sugerido:
- El soporte se define por severidad, con reglas claras y seguimiento posterior a la salida en vivo.

## Slide 9 — Modelo comercial

Mensajes:
- fee de implementación
- suscripción mensual por plan
- alcance claro

Texto sugerido:
- HMS Elite se cotiza con onboarding inicial y suscripción mensual según alcance y plan.

## Slide 10 — Cierre

CTA:
- demo guiada
- discovery
- propuesta económica

Texto sugerido:
- El siguiente paso no es “comprar software”; es validar alcance, hacer demo y cerrar propuesta.

## Regla

No llenar el deck con:
- tecnicismos innecesarios
- demasiadas pantallas
- features aisladas sin impacto de negocio

## Recomendación

Antes de convertir esto en slides finales, definir:
- vertical exacto del cliente
- cantidad de propiedades
- plan probable
- principal dolor operativo
