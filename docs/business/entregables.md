# HMS Elite — Entregables por Cliente

Fecha de referencia: 2026-03-09

## Discovery

Entregables:
- relevamiento del hotel
- alcance acordado
- plan propuesto
- fecha estimada

## Implementacion

Entregables:
- tenant configurado
- habitaciones cargadas
- usuarios base cargados
- configuracion inicial
- demo o staging validado

## Capacitacion

Entregables:
- sesion de capacitacion por rol
- checklist de uso diario
- credenciales y accesos

## Go-live

Entregables:
- validacion operativa final
- canales de soporte
- responsables definidos
- bitacora de implementacion

## Post go-live

Entregables:
- seguimiento inicial
- incidencias y decisiones registradas
- backlog de mejoras

## Criterio de aceptacion

Un entregable solo se considera cerrado cuando:
- existe evidencia
- el owner lo valida
- el cliente sabe que recibe

## Recomendacion

No mezclar entregables comerciales con entregables tecnicos.

Separar siempre:
- lo que se promete vender
- lo que se implementa
- lo que se deja fuera de alcance
