# Internal method evidence

These files are retained for traceability, but they are **not** the canonical description of the current product state. For current product and engineering documentation, start with:

- [`README.md`](../../../README.md)
- [`docs/ENGINEERING_CASE_STUDY.md`](../../ENGINEERING_CASE_STUDY.md)
- [`docs/PROJECT_STATUS.md`](../../PROJECT_STATUS.md)
- [`docs/screenshots`](../../screenshots/README.md)

Historical reports may describe branches, CI results or risks that were valid at the time they were written and were later superseded.
